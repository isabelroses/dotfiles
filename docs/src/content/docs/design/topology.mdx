## Layout

- [default.nix](https://github.com/isabelroses/dotfiles/tree/main/default.nix) - ties the sources, inputs and outputs together for each system
- [modules/output/lib/inputs.nix](https://github.com/isabelroses/dotfiles/tree/main/modules/output/lib/inputs.nix) - what we take from each source, for one system
- [modules/output/lib/mkhost.nix](https://github.com/isabelroses/dotfiles/tree/main/modules/output/lib/mkhost.nix) - evaluates one host, on NixOS or nix-darwin
- [npins](https://github.com/isabelroses/dotfiles/tree/main/npins/) - the pinned sources everything is built from

## Modules

- [output](https://github.com/isabelroses/dotfiles/tree/main/modules/output/) - what builds the outputs: lib, packages, checks and the shell
- [generic](https://github.com/isabelroses/dotfiles/tree/main/modules/generic/) - modules intended to work with any module system (e.g. home-manager, nix-darwin, etc.)
- [nixos](https://github.com/isabelroses/dotfiles/tree/main/modules/nixos/) - modules that work on NixOS
- [base](https://github.com/isabelroses/dotfiles/tree/main/modules/base/) - modules that work on either NixOS or macOS
- [darwin](https://github.com/isabelroses/dotfiles/tree/main/modules/darwin/) - modules that work on macOS
- [home](https://github.com/isabelroses/dotfiles/tree/main/modules/home/) - modules used to configure home-manager
- [iso](https://github.com/isabelroses/dotfiles/tree/main/modules/iso/) - modules used to build ISOs
